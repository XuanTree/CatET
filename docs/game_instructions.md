# 游戏玩法介绍

CatET(Cat's English Trial, 小猫的英语试炼)是一个受CET启发的游戏项目，帮助大伙在玩游戏的同时背单词。游戏核心闯关模式以拼写单词的肉鸽（rougelike）为主。

## 难度选择

游戏开始前会要求玩家选择游戏难度

- 玩家由三种难度选择：简单（Easy）普通（Normal）和困难（Hard）
  - 简单模式下游戏会从CET-4.txt中抽取单词考验玩家
  - 普通模式下游戏会大量从CET-4.txt（60%）中抽取单词考验玩家，同时少量抽取CET-6.txt的单词考验玩家（40%）
  - 困难模式下游戏会从CET-6.txt中抽取单词考验玩家

难度每提高一档，玩家的最大生命值+25%，单词拼写错误惩罚伤害+50%，弹幕伤害+100%

## 玩法设计

- 每一个关卡都有一个计时器(下面关卡设计有对计时器的详细规定)，玩家须在给定的时间内克服干扰项，拼写出正确的单词
  - 单词拼写正确或者拼写单词拼写正确一定数量后(最多不超过3个)则进入下一关
  - 单词拼写错误则扣除玩家一定的生命值
- 当玩家HP归0时，游戏结束，显示为玩家失败。或者当玩家成功闯过100个关卡后依旧保有hp，游戏结束，显示玩家胜利

- 游戏设有一个全局计时器，用于计时玩家通关的时间（若玩家失败导致游戏提前结束，则不纳入成就）
  - 通关时间将会显示在游戏开始界面，玩家可以选择反复速通的方式刷新记录，游戏主界面上仅显示最佳的时间记录
- 控制每一个关卡的时间控制在40s左右，迷宫关卡可以设置控制在为3分钟左右。考虑到游戏量和单词量的平衡性，控制玩家首次通关游戏流程在2小时内

## 关卡设计

根据玩家所选难度，挑选单词构成过关的核心元素

### 1、极速拼写

固定摄像机镜头，玩家需要在给定平坦平台上接住天上落下的字母（字母与平台有碰撞交互）。平台上有一个固定的单词，从中随机挖空。

拼写单词形式为给出部分字母，然后填空，并附有汉语和词性提示

玩家需捡起字母并将字母补空（捡起并放下），拼写正确且在规定时间内完成则进入下一关。在规定时间内若没有完成，则扣除一定的生命值，进入下一关；

若在规定时间内拼写错误，扣除一定生命值并且重置填空，让玩家重新拼写（计时器不重置）;

生命值为0时，游戏结束

关卡每隔一段时间从天上落下至少两个至多4个字母，其中必须包含至少一个至多两个需要的字母（避免玩家运气过差，在倒计时结束前都无法获取所需字母）

### 2、迷宫解密

关卡内生成由Rectangle组成的2D迷宫，其中迷宫内至少有一块空地用来摆放所需要拼写的单词，玩家需要在迷宫中解密获取正确的或者真正需要的字母来拼写单词。

拼写单词形式依旧为给出部分字母，然后填空，并附有汉语和词性提示

迷宫关卡采用跟随镜头

迷宫关卡应适当给予玩家更多的时间

若玩家拼写了错误的单词，则扣除玩家一定的生命值并重置单词的拼写（不重置倒计时），玩家需要继续在迷宫中寻找字母，并将字母带回空地拼写（当玩家脑袋上持有字母时，给予提示虚线，引导玩家回到空地）

若玩家在规定时间内拼写正确，则规定为玩家胜利，进入下一关

### 3、平台跳跃

该类型关卡没有全局计时器

根据场景大小决定该类型关卡是否采用跟随镜头。平台上随机提前刷新敌人，当玩家接触敌人时，进入到**战斗场景**。

#### 战斗场景

战斗方式采用回合制。

玩家回合：屏幕上方给出三个单词，从敌人给出的三个单词中，选中与三个单词下方中间所给的一个`词性和汉语`相符的单词，累计选对3次则直接判定玩家胜利，战斗结束，回到平台跳跃场景，并且删除该敌怪

敌怪回合：不论玩家是否选对单词，敌怪都有回合。玩家选错时给予扣除一定生命值的惩罚。玩家选对时不扣除生命值。敌怪会向玩家发射弹幕，玩家需要躲避弹幕来规避进一步扣除生命值。

当玩家生命值为0时，直接判定玩家失败

在战斗场景中，进入单词选择环节时，清除所有弹幕，敌怪停止攻击玩家，同时玩家无法移动，移动键改为选择单词，按z键选择正确答案

---

平台跳跃关卡固定设有小红旗精灵作为终点标志，玩家接触小红旗精灵时，判定玩家胜利，进入下一关

注意：玩家不能生成在距离小红旗过近的位置。平台跳跃关卡允许玩家通过走位躲避敌人规避进入战斗场景拼写单词

### 4、高难度关卡（固定每20个关卡刷新一个，即第20关，第40关，第60关，第80关，第100关）

关卡类型1与关卡类型3的结合

锁定摄像头，关卡内固定设有中心大平台和多个小平台。关卡屏幕上方会掉落字母供玩家拼写单词，同时场景上方会有boss敌怪释放弹幕；

玩家通过正确拼写单词来扣除boss敌怪的生命值，固定扣除20%（关卡内不设倒计时提示，但是有隐藏倒计时，若玩家快速拼写单词，则给予扣除boss25%生命值作为暴击奖励）

同时玩家需要躲避boss敌怪释放的弹幕扣除生命值。

玩家生命值归0时，判定玩家失败，游戏提前结束；若boss生命值归零，则判定玩家胜利，进入下一关（若该关卡为第100关，则判定玩家通关，回到游戏开始界面）

注意：简单和普通难度无单词拼写错误而给予扣除生命值惩罚，困难难度下，若玩家拼写单词错误，则给予额外生命值扣除惩罚。

单词无论拼写正确错误，都重置让玩家进行下一步拼写

## 关卡刷新权重

除了第四种类型的固定刷新，剩下的三种关卡刷新权重应该以平台跳跃为主，极速拼写次之，最后迷宫解密；

权重比为5:3:2

## 游戏数据持久化存储

对于玩家通关游戏所花的时间，需要永久化存储，每次启动游戏时，游戏需要读取并显示在开始界面；

由于游戏采用肉鸽形式，所以不设置存档读档功能

## 游戏界面

游戏界面语言全部固定用英文，没有中文备选。在开始界面和暂停界面、设置界面，玩家通过移动键选择选项，按z按键确认，按x按键返回上级菜单。
